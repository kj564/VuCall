     1→# YouTube-like Website - Work Log
     2→
     3→## Project Overview
     4→Building a YouTube-like website with Next.js 16, TypeScript, Tailwind 4, shadcn/ui, Prisma (SQLite).
     5→
     6→Key constraints:
     7→- Only `/` page route is user-visible (use URL query params + Zustand for view switching)
     8→- API routes under `/api/` are allowed
     9→- Real sample MP4 videos from Google's gtv-videos-bucket for playable videos
    10→- Picsum seeded images for thumbnails, DiceBear for channel avatars
    11→- Dark theme by default with red (YouTube) accent
    12→- Sticky footer required
    13→
    14→Architecture:
    15→- `src/lib/types.ts` - shared TypeScript types
    16→- `src/lib/store.ts` - Zustand store (view state, search, sidebar)
    17→- `src/lib/api.ts` - API client functions
    18→- `src/lib/format.ts` - view count / time formatting helpers
    19→- `src/components/youtube/*` - feature components (header, sidebar, views)
    20→- `src/app/page.tsx` - single page that switches views based on URL params
    21→- `src/app/api/*` - API routes
    22→
    23→Views (switched via `?v=ID` watch, `?c=ID` channel, `?q=query` search, default home)
